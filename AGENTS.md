# Agent Instructions

This repository's canonical agent guidance is `CLAUDE.md`.

Before changing this toolkit, read `CLAUDE.md` and follow its rules for:

- project purpose, entry points, and stage routing
- where new toolkit files belong
- generated routing surfaces and `bin/lib/skill-routing.tsv`
- scoped testing expectations
- avoiding duplicate process guidance

Keep this file as a pointer, not a second copy of the rules. If guidance changes, update
`CLAUDE.md` and any generated surfaces through the documented renderer instead of editing
multiple instruction files by hand.
