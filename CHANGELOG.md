## 2026-09-03
- **fix(gate-check): the Surface check now resolves bare filenames against `design/`, `architecture/` and `docs/`, not only the project root.** §2's Surface cells are inconsistent about paths — some carry one, some name the file bare — so `design-system.html`, `build-plan.html` and `wireframes/*.html` reported MISSING while sitting exactly where their own skills put them.
