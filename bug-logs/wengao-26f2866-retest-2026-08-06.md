## Item 1 — Import-mapping array-JsonPath bug — retest on `26f2866`

**Sandbox:** `/tmp/wengao-26f2866-test/mapping-repro/`

**Repro** (`repro-mapping.mdl`, identical to the one used against `bc3d94ef4-dirty` and RnD
`4fda072f`, sourced from `BUG-LOCAL-13`):
```
create module ZZB;
/
create non-persistent entity ZZB."RouteListItem" (
  "RoutingCode": String(100),
  "RoutingName": String(200)
);
/
create json structure ZZB."JSON_R13List"
  snippet $${
  "items": [{"routing_code": "R-1", "routing_name": "Widget Route"}]
}$$;
/
create import mapping ZZB."IMM_R13"
  with json structure ZZB."JSON_R13List"
{
  create ZZB.RouteListItem {
    RoutingCode = routing_code,
    RoutingName = routing_name
  }
};
```

**Sandbox:** `/tmp/wengao-26f2866-test/workflow-repro/`

**Repro** (reused as-is: `/tmp/wengao-5aug-test/workflow-repro/bug-wf-callmf-decision.mdl`):
```
create module ZWF01;
/
create persistent entity ZWF01.Stub (
  Status: string(50)
);
/
create microflow ZWF01.WF_ACT_DoThing ()
{
  declare $Result boolean = false;
  set $Result = true;
  return $Result;
}
/
create or replace workflow ZWF01."WF_Main"
  parameter $workflowContext: ZWF01."Stub"
  display 'ZWF01 Test Workflow'
  description 'Minimal workflow repro: one CALL MICROFLOW + one DECISION with lowercase $workflowContext'
```

This `MDL004` is an unrelated pre-existing quirk in the shared repro file itself (the stub
