Architecture Blueprint: TOEIC Buddy → Mendix

1. Module Definitions

LessonEngine

Purpose: Lesson catalog, storage, navigation

Entities: Lesson (200 lessons), LessonContent

Dependencies: None

QuizEngine

Purpose: Quiz delivery, validation, scoring

Entities: Question (800+), Answer (2000+), UserAnswer, QuizSession

Dependencies: LessonEngine

ProgressTracking

Purpose: Progress metrics, achievements, dashboards

Entities: UserProgress, LessonProgress, PerformanceMetric, Achievement

Dependencies: QuizEngine (async event listener)

2. Fit-Gap Analysis

FeatureMendix SupportGap?
Media (images/audio)Native supportNo
Scoring logicMicroflowsNo
Progress trackingNative queriesNo
Persistence (localStorage→DB)Mendix databaseNo

Verdict: No material gaps. Direct port feasible.

3. Security Model

Single-tenant, session-based authentication. Entity-level access:

  • Questions/Answers: Public (read-only)
  • UserAnswers: User (own only)
  • UserProgress: User (own only)
  • Achievements: User (own only)

4. Scalability

Target: 100+ concurrent users. No special requirements. Standard Mendix horizontal scaling.
