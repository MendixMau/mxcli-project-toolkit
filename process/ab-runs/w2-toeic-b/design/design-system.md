# Design System — TOEIC Buddy

## Color Palette

| Role | Color | Hex |
|------|-------|-----|
| Primary | Purple | #667eea |
| Secondary | Dark Purple | #764ba2 |
| Success | Green | #4caf50 |
| Error | Red | #f44336 |
| Background | White | #FFFFFF |
| Text Primary | Dark Gray | #333333 |

## Typography

- Body: Segoe UI, 14px, 400 weight
- Heading 1: 28px, 600 weight
- Label: 12px, 400 weight

## Layout Grid

- Mobile: 1 column (320px+)
- Tablet: 2 columns (768px+)
- Desktop: 3-4 columns (1024px+)

## Component Standards

- Button: Purple background, hover to dark purple
- Card: White background, light gray border, rounded corners
- Progress bar: Full width, 8px height, purple fill
- Radio button: Single selection, visual highlight on select
