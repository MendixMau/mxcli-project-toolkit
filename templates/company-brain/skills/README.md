# skills/

Own skills. Same authoring rules as the toolkit (`# Title`, `**Applies to:**`, `**Purpose:**`,
a step-by-step guide, completion criteria with denominators, the concrete bad output each rule
prevents). Client names are allowed; data is not.

Every skill gets a row in `../ROUTING.md` the day it lands, or it will never be read.
When a skill is promoted to the shared toolkit, replace it here with a pointer stub and add a
row to `PROMOTED.md`.
