## Improvement ideas, most time saved first

1. One check that names the failing statement before the exec, not after it.
2. A refusal that says which statement blocked it and why.

## BUG-DRAFT-alpha-quoted-path: a quoted path segment is stored with its quotes in one layout (2026-10-13)

> **Status:** reproduced on a throwaway copy.
> - The script passed `check`.
> - The build failed with one expression error.

**mxcli version:** v0.26.0. **Severity:** Medium.

**Repro:**

```
change $Item (
  "A" = $Other/"A"
);
```

**Workaround:** write the segment unquoted.
