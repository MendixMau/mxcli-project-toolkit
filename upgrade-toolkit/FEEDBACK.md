Status words:
- **fixed**: code changed, and a control in `controls/run-controls.sh` (`make test`) has a case it must catch and a
  case it must pass. Control names are the ones `make test` prints.
- **doc**: the fix is guidance in SKILL.md, steps/ or playbooks/. No code, so no control.
- **unproved**: code changed, but no control exercises it yet.
- **backlog #N**: not fixed yet; item N in `BACKLOG.md` owns it, with its "done when" check.
- **closed**: no work left, with the reason (stale, superseded, or another owner's).
- **open**: new and not yet triaged. The target is 0: every triage round moves each open row to one of the others.
- **won't fix**: with the reason (usually: the defect is upstream in mxcli, mx or the shared toolkit, which this
  toolkit does not edit).
